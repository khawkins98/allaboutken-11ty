Pseudomorphic Ambience Demo

This demonstrates a pure CSS atmospheric background effect that simulates warm, dappled sunlight streaming through window blinds.

Notice the effect: The blue background is brightened by the additive light effect (mix-blend-mode: plus-lighter), creating areas of lighter blue where the "sunlight" hits. The gentle sway animation brings the effect to life.

Philosophical Approach

This implementation differs from shadow-casting approaches in two key ways:

  1. CSS gradients instead of DOM elements - Uses repeating-linear-gradient for blinds slats rather than generating many individual div elements, significantly reducing DOM complexity and improving performance
  2. Additive light vs. subtractive shadows - Uses mix-blend-mode: plus-lighter to simulate sunlight streaming in, rather than multiply mode casting shadows. This creates a warmer, more luminous effect that brightens underlying content instead of darkening it

Key Features

  • Pure CSS with SVG filters - no JavaScript required
  • Gentle sway animation (11s duration) brings the effect to life
  • Respects prefers-reduced-motion and prefers-contrast: high
  • 2-layer architecture: dappled leaves + 3D perspective blinds
  • Fully accessible (aria-hidden, pointer-events: none)

Browser Support

Works in all modern browsers. The SVG wind distortion filter and CSS blend modes have excellent support across Chrome, Firefox, Safari, and Edge.

Customization

You can adjust these values in the CSS to tune the effect:

  • Gradient angle (currently 200deg) - Controls the angle of the light slats
  • Blinds opacity (currently 0.6) - Controls the intensity of the effect
  • Background color - Try different colors to see how the additive light adapts
Note: The leaves background in this demo uses a placeholder. Replace the background-image URL in .kh-ambience-leaves with your own leaves.svg or leaves.png file for the full effect.
