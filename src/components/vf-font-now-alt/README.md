# Now Alt Font

Looking for a clean, geometric sans-serif with a touch of warmth? I’ve bundled the [Now Alt font](https://usemodify.com/fonts/now-alt/) in this component to give your headings and displays a modern, friendly vibe—plus, it’s open source!

## What is Now Alt?

- **Now Alt** is a geometric, low-contrast sans-serif typeface.
- It’s a variant of the “Now” family, featuring a distinctive double-storey lowercase “a”.
- Designed by [Alfredo Marco Pradil](https://usemodify.com/fonts/now-alt/).
- Tagged as: _sans serif_, _geometric_, _grotesque / lineale_.
